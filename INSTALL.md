# Установка Twitch Drops

Подробная инструкция для новичка. Короткий вариант — внизу, в разделе
[«Если хочется коротко»](#если-хочется-коротко).

---

## Что понадобится

| | |
|---|---|
| **Обязательно** | Аккаунт Twitch, браузер, 2 минуты |
| **Для .exe** | Windows 10 или 11. Ничего больше — Python не нужен |
| **Для исходников** | Python 3.10+ и pip |
| **Время** | ~2 минуты |

---

## Способ 1: готовый .exe (проще всего)

### Шаг 1. Скачайте

Скачайте `TwitchDrops.exe` из раздела **Releases** на странице проекта.

### Шаг 2. Положите в отдельную папку

Например, `C:\TwitchDrops\`. Программа создаёт рядом `claims.csv` и
правит `config.json`, поэтому лучше не кидать её в корень диска.

### Шаг 3. Получите токен

1. Откройте `https://www.twitch.tv` и **войдите в свой аккаунт**.
2. Нажмите `F12` — откроются инструменты разработчика.
   > На Mac: `Cmd` + `Option` + `I`.
3. Слева выберите **Application** (в Chrome/Edge) или **Хранилище** (в Firefox).
4. В разделе **Cookies** → **Cookies** найдите строку `https://www.twitch.tv`.
5. В списке найдите **`auth-token`** и скопируйте его значение.

Готово? Сохраните токен в блокнот — он понадобится на следующем шаге.

> **Совет.** Установите расширение **Twitch Cookie Exporter** для Chrome или
> Firefox — оно выгружает все cookie разом, и искать `auth-token` вручную
> не придётся.

### Шаг 4. Запустите

Двойной клик по `TwitchDrops.exe`.

Откроется окно консоли, затем браузер с панелью вида
`http://127.0.0.1:8790/`. Если браузер не открылся — скопируйте адрес из
окна консоли и вставьте вручную.

### Шаг 5. Вставьте токен

Создайте рядом с `.exe` файл `config.json` — проще всего так:

1. Скопируйте `config.example.json` в эту же папку, переименуйте в
   `config.json`.
2. Откройте его Блокнотом.
3. Впишите токен между кавычками:

```json
{
    "auth_token": "СЮДА_ВСТАВЬТЕ_СВОЙ_ТОКЕН",
    "auto_claim": true,
    "poll_interval": 60
}
```

Не нужно копировать остальные ключи — программа подставит их значения
по умолчанию сама. Сохраните файл.

4. Перезапустите `TwitchDrops.exe`.

В шапке панели вместо «сервер недоступен» появится ваш логин.

### Готово

Панель работает. Дальше:

- Смотрите любой стрим — программа сама следит за прогрессом.
- Как только дропс дозреет, она его заберёт.
- Кампании появятся в панели, только когда вы **уже начали смотреть**
  нужный канал. Это ограничение Twitch, а не программы.

## Способ 2: из исходников

Нужен, если вы хотите что-то поменять в коде или запустить на macOS/Linux.

### Шаг 1. Python

Проверьте, есть ли он:

```bash
python --version
```

Если пишет, что команда не найдена — скачайте с
[python.org](https://www.python.org/downloads/) и **обязательно**
поставьте галочку *Add Python to PATH* при установке.

### Шаг 2. Зависимости

```bash
pip install -r requirements.txt
```

Единственная зависимость — `requests`. Больше ничего ставить не нужно.

### Шаг 3. Токен

Тот же способ, что в шаге 3 выше: из cookie `auth-token`.

### Шаг 4. Запуск

```bash
# панель в браузере
python twitch_drops.py --gui

# консольный режим
python twitch_drops.py
```

Токен можно передать прямо в аргументе, минуя `config.json`:

```bash
python twitch_drops.py --gui --token ВАШ_ТОКЕН
```

### Сборка .exe (по желанию)

```bash
pip install pyinstaller
python build_exe.py
```

Готовый файл появится в `dist\TwitchDrops.exe`.

## Как пользоваться

| Хочется | Как |
|---|---|
| Запустить панель | `TwitchDrops.exe` или `python twitch_drops.py --gui` |
| Забрать всё накопленное разом | Кнопка **Обновить** в панели |
| Временно не забирать | Выключить тумблер **автоклейм** |
| Посмотреть консольный вывод | `python twitch_drops.py --once` |
| Что уже заработано раньше | `python twitch_drops.py --history` |

### Что означают цвета карточек

| Цвет полосы | Значит |
|---|---|
| Зелёный | дропс дозрел, ждёт забора |
| Жёлтый | не успеваете до конца кампании |
| Красный | аккаунт игры не привязан, награда не придёт |
| Серая | кампания закончилась |

### Где смотреть

Под каждой кампанией написано **«где смотреть»** — это каналы, на которых
этот конкретный дропс капает. Названия кликабельны.

Если там написано «и ещё 500» — каналов много, показываются только первые
десять. Полный список лежит в самом ответе Twitch.

## Настройки (`config.json`)

Менять почти ничего не нужно. Только если хотите что-то конкретное:

| Ключ | По умолчанию | Зачем менять |
|---|---|---|
| `auth_token` | — | **Обязательный.** Токен из cookie |
| `auto_claim` | `true` | `false` — только смотреть, не забирать |
| `poll_interval` | `60` | Как часто опрашивать Twitch, в секундах |
| `show_channels` | `true` | `false` — не показывать списки каналов |
| `warn_minutes_before_end` | `30` | За сколько минут предупреждать о дедлайне |
| `sound` | `true` | `false` — без звука при заборе |
| `log_claims` | `true` | `false` — не писать `claims.csv` |
| `max_channels` | `8` | Сколько каналов показывать в строке |

Полный список — в разделе README.

## Решение проблем

### «Не найден auth-token»

Токен не записан в `config.json`. Проверьте, что файл лежит **в одной папке
с `.exe`**, а в поле `auth_token` стоит значение **в кавычках**, без
слова `OAuth` и без пробелов.

### «Токен отвергнут Twitch'ом»

Токен протух. Cookie `auth-token` живёт долго, но не вечно. Выйдите из
аккаунта на twitch.tv и войдите заново — Twitch выдаст новый. Скопируйте
свежий и впишите в конфиг.

### «Панель не открылась в браузере»

Скопируйте адрес из окна консоли и вставьте в браузер вручную.

### Порт занят

Панель берёт любой свободный порт. Если нужен конкретный:

```bash
TwitchDrops.exe --gui --port 9000
```

### «GQL вернул currentUser: null»

Токен не подхватился. Перезапишите его заново по инструкции выше.

### Twitch поменял внутренние запросы

Программа опирается на внутренние адреса Twitch, и они иногда меняются.
Тогда появится сообщение про `PersistedQueryNotFound`. Актуальные значения
лежат в начале `twitch_drops.py` — в переменных `PQ_INVENTORY` и `PQ_CLAIM`.

### Панель показывает ноль дропсов

Показывает только кампании, **в которых вы уже начали смотреть**. Просто
откройте стрим — и кампания появится в панели в течение минуты.

## Безопасность

**Токен — это пароль от вашего аккаунта.** Кто им владеет, тот и за вами
заходит.

- `config.json` добавлен в `.gitignore` и **никогда** не попадает в
  репозиторий. В репозитории лежит только `config.example.json` — шаблон
  без токена.
- `claims.csv` с вашей историей тоже не коммитится.
- Не выкладывайте свой `config.json` в скриншотах и на форумах.
- Удалили токен из публичного места? Смените его: выйдите из аккаунта и
  войдите заново.

### Про автоматизацию

Программа **не накручивает** время просмотра. Она только читает ваш прогресс
и нажимает «Claim» за вас — ровно то, что делает кнопка на сайте.
Смотреть стрим нужно самому.

При этом автоматизация всё равно нарушает Terms of Service Twitch, и аккаунт
теоретически могут заблокировать. Риск небольшой, но он есть. Не ставьте на
это ценный основной аккаунт.
