# Twitch Drops — трекер + автоклейм

Программа следит за прогрессом ваших дропсов на Twitch и **сама забирает награду**
в момент, когда она дозрела.

Два интерфейса на выбор: **веб-панель** (красивая, в браузере) и **консольный**
режим для тех, кому удобнее читать текст.

> **Что она не делает:** не накручивает watch-time. Смотреть стрим нужно самому,
> программа только читает ваш прогресс и жмёт «Claim».

---

## Быстрый старт

### Готовый .exe

В папке лежит `TwitchDrops.exe` — запускайте его, Python не требуется.

```
Двойной клик по  Панель.bat      →  панель в браузере
Двойной клик по  TwitchDrops.exe →  панель в браузере
```

Панель откроется в браузере по адресу вида `http://127.0.0.1:59128/`. Порт выбирается случайно свободный, точный адрес печатается в окне консоли.
Программа живёт, пока открыто её окно консоли — закрыли окно, закрылась панель.

### Из исходников

```bash
pip install -r requirements.txt
python twitch_drops.py --gui      # панель
python twitch_drops.py            # консоль
```

## Установка

Подробная пошаговая инструкция — в файле **[INSTALL.md](INSTALL.md)**.
Коротко:

1. Скачайте `TwitchDrops.exe` из раздела **Releases**.
2. Положите в отдельную папку, например `C:\TwitchDrops\`.
3. Скопируйте `auth-token` из cookie на twitch.tv
   (`F12` → Application → Cookies → `https://www.twitch.tv`).
4. Переименуйте `config.example.json` в `config.json` и впишите токен.
5. Запустите `TwitchDrops.exe` — откроется панель в браузере.

## 1. Установка из исходников

Из исходников:

```bash
pip install -r requirements.txt
```

Для `.exe` ничего не нужно.

## 2. Получение auth-token

1. Откройте `twitch.tv` под своим аккаунтом (обычное окно браузера).
2. `F12` → **Application** → **Cookies** → `https://www.twitch.tv`.
3. Скопируйте значение поля `auth-token`.

Либо поставьте расширение **Twitch Cookie Exporter** — оно умеет выгружать всю
куку целиком в текстовый файл.

> Токен ≈ пароль. Не выкладывайте его в открытые репозитории.

## 3. Запуск из исходников

```bash
# панель в браузере
python twitch_drops.py --gui

# токен в аргументе
python twitch_drops.py --token ВАШ_ТОКЕН

# только посмотреть прогресс, ничего не забирая
python twitch_drops.py --token ВАШ_ТОКЕН --no-claim

# один проход и выход
python twitch_drops.py --token ВАШ_ТОКЕН --once
```

Токен можно положить в `config.json` (скопируйте `config.example.json`) —
тогда запускать будет проще. Ключи смотрите в таблице ниже.

## 5. Ключи командной строки

| Ключ командной строки | Значение |
|---|---|
| `--token TOKEN` | auth-token; перекрывает config.json и `TWITCH_AUTH_TOKEN` |
| `--interval N` | период опроса, секунд (минимум 15, по умолчанию 60) |
| `--once` | один проход, выход |
| `--no-claim` | только показывать, ничего не забирать |
| `--no-color` | без цветов и очистки экрана |
| `--web-client` | веб-Client-ID (нужен Client-Integrity, см. ниже) |
| `--login` | OAuth-вход под своим приложением, токен сохраняется в конфиг |
| `--refresh` | обновить токен по `refresh_token` |
| `--no-channels` | не показывать списки каналов |
| `--import-catalog FILE` | разобрать каталог кампаний из JSON-файла |
| `--history` | показать уже заработанные награды и выйти |
| `--gui` | **веб-панель в браузере** |
| `--port N` | порт панели, по умолчанию любой свободный |
| `--no-browser` | не открывать браузер автоматически |

## 5а. Какие дропсы видно, а какие нет — честно

Это важно понимать, иначе будете ждать несуществующей функции.

**Программа показывает все дропсы, которые Twitch отдаёт для вашего аккаунта.**
Сейчас это 12 кампаний и 22 дропса, по каждому предмету видно прогресс, срок,
цепочку предпосылок и список каналов, где он капает.

**Полный каталог всех кампаний на Twitch она показать не может.** Причина
техническая и не обходится:

- Список кампаний, которые вы ещё не начинали, отдаёт единственная операция —
  `ViewerDropsDashboard`. Она требует `Client-Integrity`: браузерный
  отпечаток, который Twitch проверяет через Kasada.
- Запрос без него отвечает ровно так, и никакая подмена заголовков не помогает:
  ```json
  {"errors":[{"message":"failed integrity check",
              "path":["currentUser","dropCampaigns"],
              "extensions":{"code":"IntegrityCheckFailed"}}]}
  ```
- REST-эндпоинта со списком кампаний не существует. Проверены
  `api.twitch.tv/helix/entitlements/drops/campaigns` и соседние — все 404.
- Известный обход один: headless Chromium, который снимает флаг
  `navigator.webdriver`, чтобы система антиботов не заметила автоматизацию.
  Эта программа так не делает и обходить проверку не будет.

**Как всё-таки получить каталог.** Операция `ViewerDropsDashboard` работает в
обычном браузере — там отпечаток настоящий. Выгрузите ответ вручную, программа
его разберёт:

1. Откройте `https://www.twitch.tv/drops/campaigns` под своим аккаунтом.
2. `F12` → **Network** → перезагрузите страницу → фильтр `gql`.
3. Найдите запрос `ViewerDropsDashboard` → вкладка **Response**.
4. Скопируйте тело ответа в файл `catalog.json` (или через
   **Copy response** в буфер обмена).
5. Запустите:
   ```bash
   python twitch_drops.py --import-catalog catalog.json
   ```

Программа примет и «голый» массив кампаний, и полный ответ GQL.

**Чего в каталоге не будет:** вашего прогресса. Twitch не отдаёт его для
кампаний, которые вы не начинали, поэтому в импортированном файле проценты
нулевые и автоклейм не сработает. Файл годится, чтобы посмотреть, что вообще
бывает, найти нужные каналы и решить, куда идти смотреть.

## 5а. Два способа входа: cookie или OAuth

Способов два, и они не взаимозаменяемы.

### Способ 1: токен из cookie (проще, работает сразу)

Описан выше. Токен копируется из браузера, где вы уже залогинены.

### Способ 2: OAuth под своим приложением

Нужен, если вы хотите использовать **собственный** Client-ID из
[dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps).

Почему cookie-токен не подойдёт: Twitch привязывает токен к приложению, которое
его выдало, и отвергает его в паре со сторонним Client-ID — приходит
`401 The "Authorization" token is invalid`. Проверено на практике: и чтение
инвентаря, и мутация клейма возвращают 401, хотя сам токен валиден.

Через OAuth Twitch выпускает токен уже под ваше приложение, и всё сходится.

**Настройка:**

1. Создайте приложение на dev.twitch.tv, скопируйте **Client ID** и
   **Client Secret** (секрет виден только сразу после создания).
2. В поле **OAuth Redirect URLs** впишите ровно:

   ```
   http://localhost:8765
   ```

3. Впишите в `config.json`:

   ```json
   "oauth_client_id": "ваш Client ID",
   "oauth_client_secret": "ваш Client Secret",
   "oauth_redirect_uri": "http://localhost:8765"
   ```

4. Войдите:

   ```bash
   python twitch_drops.py --login
   ```

Откроется браузер, вы подтвердите доступ, программа поймает код и сохранит
токен в `config.json`. Дальше запускайте как обычно — токен будет
переавторизовываться сам, когда до истечения останется меньше 5 минут.

> `oauth_redirect_uri` обязан совпадать с указанным в консоли Twitch символ в
> символ, включая порт и слэш на конце. Иначе Twitch отклонит запрос.
> Программа специально требует `localhost` — принимать код на внешнем адресе
> она не умеет.

## 7. Про `Client-Integrity`

Twitch прикрыл GQL веб-клиента браузерным JS-челленджем (Kasada). Чисто
питоновский клиент его не проходит, поэтому по умолчанию используется
`Client-ID` мобильного приложения (`kd1unb4b3q4t58fwlpcbzcbnm76a8fp`) — для него
проверка целостности не выполняется, и мутации проходят.

Два важных момента:

* Заголовок авторизации должен быть строго `Authorization: OAuth <token>`.
  `Bearer` или `oauth` Twitch молча игнорирует — токен не подхватится.
* Если увидите `IntegrityCheckFailed` — верните в `config.json`
  `"client_id": "kd1unb4b3q4t58fwlpcbzcbnm76a8fp"`.

## 8. Если перестало работать

Twitch периодически меняет внутренние запросы. Тогда появится
`PersistedQueryNotFound` — это значит, что устарели sha256-хеши `PQ_INVENTORY` /
`PQ_CLAIM` в начале `twitch_drops.py`. Актуальный хеш лежит в бандле Twitch:
откройте `https://www.twitch.tv/drops/inventory`, найдите в JS запрос
`Inventory` и замените хеш.

## 9. Предупреждение

Автоматизация всё равно является нарушением Terms of Service Twitch и может
привести к блокировке аккаунта. Используйте на свой страх и риск, аккаунт
можно завести бесплатно.
